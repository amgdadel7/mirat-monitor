# مِرآة — مراقبة أخطاء وقت التشغيل + فحص ساكن أولي

لوحة عربية تعمل بـ Python القياسي (لا تحتاج إلى تثبيت حزم). تحتوي وضعين منفصلين:

1. **مراقبة أخطاء على طريقة Sentry بشكل أولي:** ينشأ مشروع لكل تطبيق، ويرسل SDK أحداث الاستثناءات إلى نقطة استقبال HTTP، ثم تُجمع الأحداث المتطابقة في مجموعات، وتعرض تفاصيلها وتتبعها، مع إمكان حل المشكلة أو إعادة فتحها.
2. **فحص ساكن محدود:** بقي في صفحة منفصلة تحت «فحص ساكن» أو `/scanner` لفحص روابط وملفات مشروع بشكل استدلالي؛ وهو لا يشغّل التطبيق.

## التشغيل

يتطلب Python 3.10 أو أحدث:

```bash
python3 app.py
```

افتح `http://localhost:8000`. لتغيير المنفذ: `PORT=8080 python3 app.py`. تُخزن المشاريع والأحداث في قاعدة SQLite محلية باسم `mirat.sqlite3`.

## ربط التطبيق

من لوحة المراقبة أنشئ مشروعاً واختر المنصة، ثم استخدم مقطع SDK المعروض:

- **JavaScript بالمتصفح:** أضف وسم `<script>` المولد إلى صفحات التطبيق. يلتقط أخطاء JavaScript غير المعالجة ورفض الوعود.
- **Python:** نزّل `mirat_sdk.py` إلى مشروعك واستدعِ `init(DSN)` عند بدء التطبيق. يتضمن SDK التقاط الاستثناءات غير المعالجة في الخيط الرئيسي والخيوط، مع خيار `capture_logs=True`.
- **Node.js:** نزّل `mirat-node.js` واستدعِ `init(DSN)` قبل تشغيل التطبيق.
- **لغات أخرى:** أرسل JSON إلى عنوان DSN الخاص بالمشروع عبر `POST`، مثل `{"type":"ValueError","message":"example","stacktrace":"..."}`.

زر «إرسال حدث تجريبي» يختبر خط الاستقبال واللوحة دون الحاجة إلى تطبيق مربوط. لا يُرسل SDK تلقائياً محتوى الطلبات أو كلمات المرور، لكن قد تحتوي رسائل الأخطاء أو stack traces التي يرسلها التطبيق على بيانات حساسة؛ راجع سياساتك وقلّم/نقّح البيانات قبل الإرسال.

## الحدود مقارنة بمنصة Sentry كاملة

هذه **نسخة MVP** وليست بديلاً مكافئاً لـ Sentry. هي لا تفحص المشروع كله تلقائياً ولا تعرف أخطاء الماضي إلا إذا كانت الأحداث قد أُرسلت إليها. التغطية تعتمد على تثبيت SDK لكل runtime؛ ونسخة المتصفح لا ترى أخطاء الخادم. لا توجد حالياً خرائط source maps، تتبع أداء/APM، breadcrumbs، جلسات مستخدمين، تكاملات Slack/GitHub، إصدارات/releases متقدمة، تنبيهات، أو أكثر من مستخدم. التجميع الأساسي حسب نوع الاستثناء ورسالة الخطأ. تُحذف سجلات الأحداث الأقدم من 90 يوماً.

الفاحص الساكن المنفصل محدود: لا ينفذ اختبارات أو منطق الأعمال ولا يضمن اكتشاف كل عيب. إنذاراته احتمالية.

## الأمان والنشر

المشروع في وضعه الحالي **للتجربة المحلية فقط**: لا توجد مصادقة للوحة أو صلاحيات مستخدمين أو تحديد معدلات/حصص، كما أن DSN يتيح إرسال أحداث للمشروع ولا يمثل مفتاحاً سرياً. لا تعرض الخادم مباشرةً على الإنترنت. قبل النشر أضف مصادقة، حماية CSRF حيث تنطبق، تحديد معدلات وحجم وتخزين، عزل وصول الشبكة والملفات، HTTPS، سياسات حذف وتنقيح بيانات، وسجلات تدقيق. لا ترسل بيانات شخصية أو أسراراً في الأحداث.
